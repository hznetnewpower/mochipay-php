MochiPay PHP SDK 1.0.1 发布步骤

1. 将本次 README.md、src/Client.php 和 tests/run.php 的改动提交到 https://github.com/hznetnewpower/mochipay-php 的 main 分支。
2. 等待 GitHub Actions 的 PHP SDK checks 通过，再创建并推送 v1.0.1 标签；标签必须指向通过检查的提交。
3. 在 GitHub Releases 使用 v1.0.1 标签发布 “MochiPay PHP SDK 1.0.1”。
4. Packagist 已有 mochipay/php-sdk，等待自动更新后确认页面出现 1.0.1；若没有更新，登录原包管理页面手动执行 Update。

这次增加原生 TRX_TRON 方法；它与 USDT_TRC20 是不同资产。README 同步说明人工确认差额付款时必须以认证查询返回的严格布尔值为准。

本地已通过 PHP 7.4 离线检查和语法检查。尚未调用真实 API 或创建订单。不得将 API 密钥、订阅数据或生产配置提交到公开仓库。
